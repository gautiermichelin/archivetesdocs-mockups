# ArchiveTesDocs — Maquettes de refonte UI

Maquettes interactives pour la refonte de l'interface ArchiveTesDocs.

**Voir les maquettes :** [https://gautiermichelin.github.io/archivetesdocs-mockups/](https://gautiermichelin.github.io/archivetesdocs-mockups/)

## Vues disponibles

1. **Accueil** — Tableau de bord avec compteurs de demandes et actions rapides
2. **Utilisateurs** — Administration des comptes utilisateurs
3. **Services** — Paramétrage des services et référentiels
4. **File de transfert** — Liste des demandes avec panneau de transfert
5. **Demandes (modale)** — Détail des demandes de transfert
6. **Saisie d'archive** — Formulaire complet de création d'unité d'archives

## Choix de design

- **Typographie** : DM Sans (corps) + Playfair Display (titres)
- **Palette** : Navy (#0F1B2D), bleu (#2563EB), accents dorés (#D97706), fond sable (#FEFBF6)
- **Layout** : Sidebar + contenu principal (fidèle au positionnement existant)

## Développement local

```bash
npm install
npm run dev
```

## Technologie

Vite + React. Déploiement automatique via GitHub Actions sur GitHub Pages.
